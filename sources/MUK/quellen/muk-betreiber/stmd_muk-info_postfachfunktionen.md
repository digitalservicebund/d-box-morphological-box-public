# Postfachfunktionen

## Postfachfunktionen

Um die vollständige Digitalisierung des Antragsprozesses zu gewährleisten, ist es notwendig auch den Rückkanal mitzudenken. Mein Unternehmenskonto bietet insoweit zwei Postfächer mit unterschiedlichen Funktionalitäten.

### Postfach 2.0

Das Postfach 2.0 basiert technologisch auf dem ELSTER-Postfach, über das seit einigen Jahren digitale Steuerbescheide rechtsverbindlich bekannt gegeben werden können. Dieses Postfach wird nun außerhalb der Steuer verwendet. Mitteilungen, die im Postfach 2.0 liegen, können auch über ELSTER abgerufen werden. Jedem ELSTER-Organisationszertifikat ist genau ein Benutzerkonto und damit genau ein Postfach 2.0 zugeordnet.

Beantragt eine Mitarbeiterin bzw. ein Mitarbeiter über einen Onlinedienst z.B. eine Genehmigung, wird diese Genehmigung in genau das Postfach 2.0 der beantragenden Person übermittelt. Andere Mitarbeiterinnen und Mitarbeiter mit einem ELSTER-Organisationszertifikat haben in der Regel auf das Postfach 2.0, in das die Genehmigung übermittelt wird, keinen Zugriff.

### OZG-PLUS-Postfach

Mit dem OZG-PLUS-Postfach wird insbesondere der Anforderung Rechnung getragen, Funktionspostfächer anzubieten, auf die mehrere Personen gleichzeitig Zugriff haben können. So haben insbesondere größere Unternehmen die Möglichkeit, die Postfachkommunikation auf die internen Strukturen anzupassen.

Behörden können so Bescheide und andere Mitteilungen digital in die Postfächer von Unternehmen senden. Perspektivisch soll eine Auswahl zwischen beiden Postfächern für jede digitale Verwaltungsleistung möglich sein, sodass Unternehmen die Auswahl über die benötigten Funktionen haben.
