# Sonstige Organisationen Offen für alle Organisationen mit Steuernummer

Mein Unternehmenskonto kann von allen Organisationen genutzt werden, die über eine deutsche Steuernummer verfügen. Abgedeckt sind damit nicht nur Unternehmen, sondern z.B. auch Vereine, sofern ein steuerlicher Bezug besteht. Weitere Informationen zu den Funktionalitäten von Mein Unternehmenskonto finden Sie [hier](https://info.mein-unternehmenskonto.de/ueberblick-funktionalitaeten/funktionalitaeten/).
