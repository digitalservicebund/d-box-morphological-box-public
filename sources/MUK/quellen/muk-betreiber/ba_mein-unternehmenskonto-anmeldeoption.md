# Mein Unternehmenskonto: Anmeldeoption für Unternehmen

Mit „Mein Unternehmenskonto“ stellen wir Ihnen – Unternehmen und Mitarbeitenden – eine sichere Anmeldeoptionen auf Basis von ELSTER zur Verfügung.

Sie können für Ihre Mitarbeitenden ELSTER-Organisationszertifikate beantragen, welche eine Anmeldung ohne zusätzliche Geräte wie etwa Diensthandys oder spezielle Authentifizierungssoftware ermöglichen.

**Hinweis zur Anmeldung**: Sie können alternativ zu „Mein Unternehmenskonto“ auch das [Konto der Bundesagentur für Arbeit zur Anmeldung nutzen](/anmeldung-varianten "Anmeldung").

## Technische Voraussetzungen

Um „Mein Unternehmenskonto“ zur Anmeldung am Portal der Bundesagentur für Arbeit nutzen zu können, müssen folgende Voraussetzungen erfüllt sein:

1.  Ein Endgerät (idealerweise Laptop für einfache Bedienbarkeit) mit Internetzugang und einem aktuellen Browser.
2.  Ein bestehendes „[Mein Unternehmenskonto](https://www.elster.de/eportal/unternehmerorientiert/registrierungsprozess "„Mein Unternehmenskonto“ registrieren")“
3.  Ein bestehendes [Konto bei der Bundesagentur für Arbeit](/anmeldung-varianten "Anmeldung"). In diesem Konto müssen Sie einmalig Ihr „Mein Unternehmenskonto“ [einrichten](https://www.arbeitsagentur.de/link/kontoeinstellungen "Kontoeinstellungen").

## Schritt-für-Schritt-Anleitung

1\. Schritt

### Schritt 1 von 6: Registrierung: Mein Unternehmenskonto

Registrieren Sie ein „Mein Unternehmenskonto“ und hinterlegen Sie Ihr ELSTER-Organisationszertifikat. Dazu können Sie [dieser Anleitung folgen](https://www.elster.de/eportal/unternehmerorientiert/registrierungsprozess "Registrierung von Mein Unternehmenskonto").

2\. Schritt

### Schritt 2 von 6: Registrierung: Bundesagentur für Arbeit

Registrieren Sie sich für ein Konto der Bundesagentur für Arbeit – falls noch nicht geschehen.

[Jetzt registrieren](https://web.arbeitsagentur.de/oiambk/oiambk-registrierung-ui/registrierung?redirectUrl=https%3A%2F%2Fweb.arbeitsagentur.de%2Fprofil%2Fprofil-ui%2Fpd%2F%3Fforce-profile-selection%3Dtrue "Registrierung eines Kontos bei der BA")

3\. Schritt

### Schritt 3 von 6: Anmeldung: Bundesagentur für Arbeit

Melden Sie sich für die erstmalige Einrichtung Ihres „Mein Unternehmenskonto“ zwingend über Ihr Konto bei der Bundesagentur für Arbeit an. 

4\. Schritt

### Schritt 4 von 6: „Mein Unternehmenskonto“ auswählen

Nach der Anmeldung erscheint ein Sicherheitshinweis, bei dem Sie „Mein Unternehmenskonto“ auswählen. Sie werden aufgefordert, die Einrichtung zu starten. 

Folgen Sie den Anweisungen, um die Verbindung herzustellen. Die Einrichtung erfolgt direkt im Anschluss und ist Voraussetzung für die spätere Anmeldung mit Ihrem ELSTER-Organisationszertifikat.

5\. Schritt

### Schritt 5 von 6: Weiterleitung auf „Mein Unternehmenskonto“

Sie werden auf die Webseite von „Mein Unternehmenskonto“ weitergeleitet. Folgen Sie dort den Anweisungen, um sich anzumelden. Nach der Anmeldung werden Sie in das Portal der Bundesagentur für Arbeit zurückgeleitet.

6\. Schritt

### Schritt 6 von 6: Anmeldeoption „Mein Unternehmenskonto“ nutzen

Jetzt können Sie die Anmeldeoption „Mein Unternehmenskonto“ zur [Anmeldung im Portal der Bundesagentur für Arbeit](https://sso.arbeitsagentur.de/auth/realms/OCP/protocol/openid-connect/auth?client_id=profil-online&redirect_uri=https%3A%2F%2Fweb.arbeitsagentur.de%2Fprofil%2Fprofil-ui%2Fpd%2F&response_type=code&scope=openid&state=b2c94d75a59a414686cb1091a70d5036&code_challenge=ksz78oITf1Yb7Ft2OycO5xi6VJo1zTwT78uWZEHf2lw&code_challenge_method=S256&acr_values=login-filter%3Dprivatperson%2Cunternehmen%2Cpartner&correlation-id=1c503832-1f1f-21c2-a8f3-795e88ede99c "Anmeldung im BA-Portal") nutzen. 

In den Kontoeinstellungen können Sie die Anmeldeoption „Mein Unternehmenskonto“ jederzeit wieder entfernen. 

## Vertrauensniveau

Die Anmeldung mit ELSTER-Organisationszertifikat über „Mein Unternehmenskonto“ erreicht das Vertrauensniveau „substanziell“ und ermöglicht den Zugriff auf alle Funktionen des Online-Portals.

## Vorteile durch Nutzung von „Mein Unternehmenskonto“

- positiv:Zentrale Verwaltung aller Unternehmenszugänge über ein einziges Konto
- positiv:Rechtskonforme Authentifizierung für behördliche Prozesse
- positiv:Rollen und Berechtigungen für Mitarbeitende einfach steuerbar

## Antworten auf häufige Fragen

Nur für Mitarbeitende von Unternehmen, die im Portal der Bundesagentur für Arbeit für ein Unternehmen agieren möchten. „Mein Unternehmenskonto“ muss zur Anmeldung eingerichtet werden, eine Anleitung finden Sie weiter oben.

Sie können sich für „Mein Unternehmenskonto“ [im Portal von Elster registrieren](https://www.elster.de/eportal/unternehmerorientiert/registrierungsprozess "„Mein Unternehmenskonto“im Elster-Portal"). Wichtige Fragen und Antworten finden Sie auf der [Hilfeseite von „Mein Unternehmenskonto“](https://info.mein-unternehmenskonto.de/hilfe/ "„Mein Unternehmenskonto“ Hilfe-Seite"). 

Ja, allgemein muss zur Nutzung von „Mein Unternehmenskonto“ ein ELSTER-Organisationszertifikat hinterlegt werden. Informationen dazu finden sie im [„Mein Unternehmenskonto“-Leitfaden](https://info.mein-unternehmenskonto.de/wp-content/uploads/2024/08/20240827_Zertifikatsleitfaden.pdf "„Mein Unternehmenskonto“-Leitfaden"). Erst dann ist eine Nutzung von „Mein Unternehmenskonto“ im Portal der Bundesagentur für Arbeit und anderswo möglich.

Eine Anleitung zur Einrichtung von „Mein Unternehmenskonto“ im Konto der Bundesagentur für Arbeit finden Sie weiter oben.  
 

Mehr Informationen zur Beantragung eines ELSTER-Organisationszertifikats finden Sie auf der [Hilfeseite von „Mein Unternehmenskonto“](https://info.mein-unternehmenskonto.de/hilfe/ "„Mein Unternehmenskonto“ Hilfe-Seite"). Pro Unternehmen können bis zu 5000 Zertifikate beantragt werden.

„Mein Unternehmenskonto“ ist eine von mehreren Optionen, um sich im Portal der Bundesagentur für Arbeit anzumelden.

Sobald Sie angemeldet sind, ermöglichen es Ihnen Profile für unterschiedliche Personen oder Unternehmen, zu handeln – unabhängig von der Anmeldeoption. Mehr Informationen zur Funktionsweise von Profilen finden sie auf der Seite [Ein Konto, mehrere Profile](/ein-konto-mehrere-profile "Ein Konto, mehrere Profile").  
 

Die Bundesagentur für Arbeit unterstützt „Mein Unternehmenskonto“ zur Anmeldung im Online-Portal. Die von „Mein Unternehmenskonto“ angebotene Postfachfunktion und deren Berechtigungssteuerung sind aktuell nicht integriert.

„Mein Unternehmenskonto“ wird vom Bayerischen Staatsministerium für Digitales zur Verfügung gestellt. Es kann genutzt werden, um wirtschaftsbezogene Verwaltungsleistungen in Anspruch zu nehmen und basiert auf ELSTER.
