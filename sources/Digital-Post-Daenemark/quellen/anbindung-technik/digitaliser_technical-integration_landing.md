Den samlede, tekniske dokumentation for teknisk integration til Digital Post.

Word version af gældende og forrige version er tilgængelig til sammenligning.

Senest opdateret: 20-02-2026, v1.51

Ændringer:

- Mailbox services
  - Updated required roles
- Querying Identities, Direct Privileges, Identity-group privileges, and Privilege Type
  - Updated privilege type description
- Push notification integrations
  - Updated example under “Subscription to push notification”
- Querying the event-log
  - Updated description & examples for “Using wildcard”
