Templates

   To send an email, text message or letter with Notify, you need to add a reusable message template.

   Templates let you send the same thing to lots of people, as often as you need to, without writing a new message each time.

   Go to the Templates page to:
     * add a new template
     * send messages
     * copy an existing template
     * add folders and organise your templates
