# Neo Rust SDK

## About

This is repository contains the Neo Rust SDK for the
[Matrix-based G2X communication pilot](https://gitlab.opencode.de/fitko/matrix-g2x),
code name "Neo".

It extends the upstream [Matrix Rust SDK](https://github.com/matrix-org/matrix-rust-sdk)
with use-case specific features.
