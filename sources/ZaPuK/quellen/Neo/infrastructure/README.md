# Neo Infrastructure

This repository contains definitions of the server environments
used in the "Neo" project.
Infrastructure in this project is generally managed
using an Infrastructure as Code (IaC) approach.

All applications are hosted on Kubernetes,
matching the strategy of the [D-stack](https://deutschland-stack.gov.de/).
