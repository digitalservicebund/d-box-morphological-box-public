   Push-Benachrichtigungen für „Mein Postkorb“

Wann hilft mir diese Anleitung?

     * Wenn Sie über das Eintreffen von behördlichen Schriftstücken in
       „Mein Postkorb“ über Push-Benachrichtigungen auf Ihrem Smartphone
       oder PC informiert werden möchten.

   Wie kann ich Push-Benachrichtigungen für „Mein Postkorb“ aktivieren?

   Warum sollte ich Push-Benachrichtigungen für „Mein Postkorb“
   aktivieren?

Wie kann ich Push-Benachrichtigungen für „Mein Postkorb” aktivieren?

    1. Falls Sie nicht angemeldet sind, melden Sie sich auf
       oesterreich.gv.at mit Ihrer ID Austria an.
    2. Im Menüpunkt „Profil“ wählen Sie „Einstellungen“.
    3. Unter der Überschrift „Benachrichtigungen“ im Abschnitt "Mein
       Postkorb" finden Sie die Option „Push-Benachrichtigung erhalten“.
       Aktivieren Sie diese Einstellung. Bitte beachten Sie, dass diese
       Einstellung nur zur Verfügung steht, wenn Sie für die elektronische
       Zustellung registriert sind.
    4. Erteilen Sie in der darauf folgenden Abfrage Ihre Zustimmung für
       den Erhalt von Push-Benachrichtigungen von oesterreich.gv.at auf
       diesem Gerät/Browser.

   Weitere Informationen finden Sie hier:
     * FAQ zu Push-Benachrichtigungen
     * Ausführliche Anleitung für die Aktivierung von
       Push-Benachrichtigungen, inklusive spezifischer Hinweise für
       iPhone-Benutzer.

Warum sollte ich Push-Benachrichtigungen für „Mein Postkorb“ aktivieren?

     * Push-Benachrichtigungen helfen Ihnen dabei, keine behördliche
       Zustellung zu verpassen oder zu übersehen.

Hinweis

   Unabhängig von der Aktivierung von Push-Benachrichtigungen, erhalten
   Sie jedes Mal, wenn ein neues Schriftstück in „Mein Postkorb"
   eingetroffen ist, eine Verständigung per E-Mail.
